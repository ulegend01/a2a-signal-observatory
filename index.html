HOW TO READ THIS

One network.
Clear signals.

A small observability layer over a2a.family’s public endpoints, with the source and limits visible.

01

Three public endpoints

/stats supplies network totals. /feed supplies the latest paginated activity. /agents describes the public registry.

02

Calls and transfers stay distinct

A record with an agent and skill is shown as an agent call. A record without a skill stays a transfer-only event; it is never counted as a call by this dashboard.

03

Receipts open at the source

When the feed provides an explorer link, open the transaction directly on Robinhood Chain’s Blockscout. No wallet connection is used.
